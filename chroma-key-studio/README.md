# 实时绿幕抠像 · 虚拟背景合成器

纯前端实现的浏览器实时视频色度键抠像与虚拟背景合成工具。零依赖、零构建，打开即用。

## 运行方式

**方式一（最简单）**：直接双击 `index.html` 用现代浏览器（Chrome / Edge / Firefox）打开即可。

**方式二（本地服务器）**：

```bash
cd chroma-key-studio
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

打开后默认进入**内置测试画面**（动画绿幕场景），无需摄像头即可立即看到「原始 / 遮罩 / 合成」三路实时效果。点击「📷 摄像头」或「📁 视频文件」切换视频源。

## 技术架构

```
视频源 ──► 视频纹理 ──► Pass1 抠像+溢色+调色 (key.frag)
                          │ RGBA(前景, α)
                          ▼
                   Pass2 腐蚀/膨胀 H+V (morph.frag)
                   Pass3 中值去噪 (median.frag)
                   Pass4 高斯羽化 H+V (blur.frag)
                   Pass5 半透明保留 (keepsemi.frag)
                          ▼
                   Pass6 背景合成 (composite.frag) ──► 屏幕
                          │
                          └─► blit 降采样 ──► readPixels ──► 遮罩预览 + 直方图
```

- `js/pipeline-gl.js` — WebGL2 多 Pass 管线（FBO 乒乓、GPU 计时查询）
- `js/pipeline-cpu.js` — CPU Canvas 回退（同一套算法的 TypedArray 实现，形态学半径限 4px 保证实时）
- `js/shaders.js` — 全部 GLSL（色度键距离在 RGB/YUV/HSV 三空间与 CPU 端公式严格一致）
- `js/sources.js` — 摄像头/文件/测试画面源管理，rVFC 帧率估算、VideoFrame 色彩空间探测
- `js/background.js` — 背景素材与平均色采样（色彩匹配/光照统一）
- `js/presets.js` — 内置预设 + IndexedDB + JSON 导入导出
- `js/perf.js` — FPS/耗时/丢帧统计
- `js/ui.js` — data-bind 声明式控件绑定 + 曲线编辑器
- `js/main.js` — 渲染循环、三路预览、对比/放大镜、动态质量

## 使用提示

1. **取色**：点「💧 吸管取色」→ 在「原始画面」上点击绿幕区域，自动设置键色。
2. **调边缘**：先调「相似度阈值」让背景透明，再用「平滑度/羽化」柔化边缘，「边缘收缩」去绿边，最后开「溢色抑制」去前景反光。
3. **低光照场景**：直接应用内置「低光照」预设（更高阈值 + 去噪 + 提亮）。
4. **性能**：WebGL2 模式 1080p 可实时；CPU 回退建议降采样到 0.5 以下；开启动态质量可自动维稳 30fps。
5. **快捷键**：空格 = 播放/暂停。
